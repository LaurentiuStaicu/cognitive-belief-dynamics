## Overall result

The current design does **not** satisfy the Phase D recovery convention.

`minimum_grid_recovery_probability = 0.225`

`all_core_grid_cells_pass = false`

Seventeen of the 24 generator × regime × trial-count cells fall below the CEM
design convention of recovery >= 0.80.

This is a design-identifiability result. It is not evidence that either EVSD or
2HT is the true human recognition architecture.

## Aggregate generator → selected confusion matrix

Across 2,400 replicates generated by each family:

| Generator | EVSD selected | 2HT selected | Inconclusive |
| --- | ---: | ---: | ---: |
| EVSD | 1,649 (68.71%) | 70 (2.92%) | 681 (28.38%) |
| 2HT | 113 (4.71%) | 1,401 (58.38%) | 886 (36.92%) |

The dominant failure mode is therefore not systematic inversion of the models.
It is failure to obtain a decisive result under the deliberately conservative
requirement that train AIC and held-out predictive log likelihood agree.

## Interpretation of the sweep

The committed benchmark contains multiple trial counts because it is a prospective
design sweep. Therefore two statements should be kept distinct:

1. the strict implementation flag `all_core_grid_cells_pass` is false because
   exploratory low-trial cells are included in the core grid;
2. the practically relevant design-selection question is whether **any tested
   trial-count design** passes all generator × memory-regime cells.

The second answer is also **no**: 320 + 320 passes only 5 / 6 cells.

Therefore the substantive verdict is unchanged by this distinction.

A future contract revision should encode design adequacy per candidate design
configuration rather than requiring every exploratory trial-count row to pass.

## Next refinement

The first refinement should isolate the **trial-count axis** while keeping the
five operating points fixed.

Reason:

- recovery improves monotonically with trial count in the difficult EVSD-weak
  region: 0.365 → 0.505 → 0.645 → 0.745;
- wrong selection at 320 is already only 0.005;
- the remaining 0.250 is mostly inconclusive.

Changing trial count and operating-point placement simultaneously would make it
harder to identify which design change produced any improvement.

Recommended next targeted sweep:

- 480 + 480;
- 640 + 640;
- 960 + 960 target/foil trials per operating point;

with the same five bias points and the same 200-replicate convention.

If EVSD-weak remains below 0.80 despite the increased trial count, the subsequent
step should compare alternative/wider operating-point placement while holding the
selected trial count fixed.

## Methodological boundary

Wilson & Collins (2019) emphasize that model recovery depends strongly on the
parameter regimes used for simulation and recommend reporting the generator ×
fitted-model confusion matrix. They also distinguish model recovery from
parameter recovery.

Simulator-based experimental-design work likewise treats experimental design as
part of the model-selection problem: data should be designed to be informative
for discrimination rather than merely increased without checking whether the
models become distinguishable.

The current result is therefore used exactly as intended: a failed recovery region
triggers experimental-design refinement rather than a claim about which cognitive
model is true.
