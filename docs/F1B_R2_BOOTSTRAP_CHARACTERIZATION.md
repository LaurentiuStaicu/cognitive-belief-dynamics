# F1b R2 Bootstrap Characterization Harness

Status: **NON_AUTHORITATIVE_R2_BOOTSTRAP_CHARACTERIZATION_DESIGN**

Issue: #145  
Controlled-departure baseline: `5dfef7f6da37384beb233fbbb0f6b1c86dc876de`

## Purpose

This harness connects the integrated controlled-departure geometry to the integrated simulation-calibrated ADD/CBD restriction tests.

It is designed to characterize:
- false rejection under CBD and ADD nulls;
- CBD departure detection;
- ADD specificity for the standalone-accuracy negative-control axis;
- ADD decisions on other departures;
- bootstrap calibration/fitting failures;
- held-out participant/item predictive deltas.

It does not choose one model winner.

## Full non-authoritative design search

Candidate bootstrap draw counts:

`49, 99, 199`

Candidate staged evaluation replicate counts:

`5, 10, 20`

Neither grid is authoritative.

The full design applies the tests to all controlled departures generated by the 0.10 / 0.25 / 0.50 RMS geometry.

## Independent random streams

Synthetic evaluation datasets and parametric-bootstrap calibration use separate deterministic seed streams.

Bootstrap draws for one evaluation dataset therefore cannot reuse that dataset's generator stream.

## Null calibration

CBD false rejection is evaluated under:
- CBD_ANCHOR_1;
- CBD_ANCHOR_2.

ADD false rejection is evaluated under:
- ADD_ANCHOR.

## Departure evaluation

Every controlled AP-GENERAL departure is tested independently against:
- CBD-complement restriction;
- ADD restriction.

Roles are explicit:

- `CBD_DEPARTURE_DETECTION`;
- `ADD_SPECIFICITY_NEGATIVE_CONTROL` for the standalone-accuracy axis generated from CBD∩ADD anchors;
- `ADD_DEPARTURE_DIAGNOSTIC` for complement/combined departures.

Failure to reject is not evidence that a restriction is true.

## Outcomes and uncertainty

Every evaluation replicate retains:
- observed statistic;
- empirical bootstrap critical value;
- plus-one p-value;
- rejected/not rejected;
- fit failure;
- bootstrap calibration failure;
- successful bootstrap draws;
- bootstrap fit failures;
- held-out participant/item predictive deltas.

Aggregate rejection rates report Wilson 95% intervals.

Fit/calibration failures remain separate from rejection probability.

## Smoke versus design search

CI uses only:
- 2 bootstrap draws;
- 1 evaluation replicate;
- one standalone-accuracy departure.

This verifies execution only.

It is not a characterization result and cannot support a draw-count or replicate-count decision.
