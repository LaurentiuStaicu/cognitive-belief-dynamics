# Alpha 0.4.2a0 Phase C — Theory integration and bounded M1.E3 comparator

Status: stacked implementation phase on top of Phase B. Do not merge directly to `main` while Alpha 0.4.2a0 release preparation is incomplete.

## Purpose

Phase C exposes the already implemented M1.E3 Headline Access Gate without changing its scientific contract.

The public explanatory surface is restricted to:

`PreviewImpression → Hneg → Paccess → Access`

and to comparison of the nested models:

- M1.E3-NULL: `logit(Paccess) = b0`;
- M1.E3-A: `logit(Paccess) = b0 + beta_hneg × Hneg`.

No downstream propagation is added.

## Comparator invariants

The Understanding → Mechanisms comparator holds fixed in both conditions:

- story ID;
- source ID;
- image ID;
- fact compatibility;
- one registered PreviewImpression.

Only the project-controlled binary cue `Hneg ∈ {0,1}` changes.

The UI reports the exact deterministic `Paccess` values generated by the Python reference export. It also shows the single illustrative Bernoulli draw already present in Phase B, but scientific validation remains based on the probability contrast rather than one sampled Access outcome.

## Empirical context

The active target remains `TARGET.M1.E3.ROBERTSON_2023`.

The comparator exposes the platform-native filtered-sample counts preserved in the registry:

- 12,448 experiments;
- 53,699 headline variants from the main Results text;
- more than 205 million impressions;

## Scientific boundary

The UI must preserve this inequality explicitly:

`PreviewImpression != Access != Attention != Encoding != Belief != EngageIntent != Share`.

A non-click leaves `PreviewImpression` intact.

The Phase C web code reads the deterministic `m1_access.json` export. It does not import or mutate the M0 simulator, M1.E1 editorial state or M1.E2 presentation state.

No temporal curve is introduced because the registered comparator is between conditions, not longitudinal.

- exact NULL and Hneg-gate probabilities;

- scientific-boundary text;
- Theory → Mechanisms deep linking;
- keyboard/focus destination;
- mobile horizontal-overflow regression.
