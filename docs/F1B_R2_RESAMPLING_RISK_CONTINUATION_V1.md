## Reproduction procedure

For every eligible unresolved run:

1. locate the exact run in the paired artifact;
2. regenerate its synthetic dataset from:
   - paired master seed;
   - versioned scientific dataset ID;
   - evaluation replicate;
3. recompute the canonical dataset SHA-256;
4. require exact equality with the retained fingerprint;
5. refit the exact observed restriction pair;
6. compare observed statistic to the retained value;
7. require absolute delta <= `1e-10`;
8. regenerate bootstrap draw indices 0…198 only;
9. use the exact retained bootstrap stream seed and restriction-specific draw identity;
10. canonicalize the regenerated 199-attempt sequence;
11. require exact SHA-256 equality with:
    - the paired-source sequence;
    - the Stage-B stream checkpoint.

No bootstrap draw index >=199 is generated.

## Sharding

`SHA256(run_id) modulo 8`

The shard assignment is independent of:
- role;

The combiner requires:
- all 8 shard IDs;
- no duplicate shard;
- 224 unique run IDs;
- invariant source/config/file provenance.

## Why full 199-attempt reproduction is required

Regenerating only the dataset or only a few bootstrap indices would not prove that the current fitter and bootstrap mechanism continue the exact retained stochastic stream.

The canonical 199-attempt hash verifies the complete retained prefix before a new draw is permitted.

This costs computation but keeps Stage C2 scientifically auditable.
