# F1b R2 S4 broad execution topology gate

Issue: #259

Status: **EXECUTION TOPOLOGY FROZEN / BROAD NUMERICAL EXECUTION NOT YET RUN**

## Purpose

This gate converts the retained S4 design into a deterministic, platform-safe execution topology without changing any scientific estimand.

The retained broad design is:
- 15,000 scientific runs;
- four M2-eligible inference methods;
- 60,000 method/run identities;
- 3,360 exact M2 method rows authorized for reuse;
- 56,640 new method executions.

## Why waves are required

GitHub Actions permits a maximum of 256 jobs generated by one matrix in a workflow run.

The broad characterization therefore cannot use one matrix containing all scientific runs or all shards.

The topology freezes four separate wave executions.

W1-W3 each contain:
- 3,750 new scientific runs;

## Deterministic shard partition

Each wave uses exactly 250 shards.

Assignment reuses the same deterministic sharding rule already used in M2:

`int.from_bytes(SHA256(scientific_run_id)[:8], "big") % 250`

where the SHA-256 expression refers to the digest bytes.

All four methods for one scientific run remain in the same shard.

Imported W0 evidence remains attached to the same scientific-run shard.

No method-specific sharding is allowed.

The complete frozen wave/shard assignment has canonical SHA-256:

`7d37f2384c1003490a4b6e7a091f8648ed61e72241f964d3ce0336229f63dbce`

Verified scientific-run counts per shard are:
- W0: 5..29;
- W1: 5..27;
- W2: 6..27;
- W3: 4..27.

Thus all 1,000 frozen shards are non-empty.

## Wave completeness

A wave is complete only if:
- exactly 250 shard artifacts are present;
- every expected scientific run appears exactly once;
- every scientific run has exactly four method rows after imported and newly executed evidence are combined;
- no duplicate scientific-run or method-row identity exists;
- unresolved and refit-failure outcomes remain in denominators;
- no replacement replicate is introduced.

Each wave has one separate combine job after all 250 matrix jobs.

The combine job is not itself a matrix member.

## Final combine

Scientific interpretation is forbidden before all four waves are complete.

The final combine must require:
- W0, W1, W2 and W3;
- 15,000 unique scientific runs;
- 60,000 unique method/run identities;
- 3,360 imported M2 method rows;
- 56,640 newly executed method rows;
- the retained canonical S4 scientific-run-ID digest;
- the retained imported method-row digest;
- exact method order:
  POPULATION,
  HIERARCHICAL_0.5X,
  HIERARCHICAL_1X,
  HIERARCHICAL_2X.

The final result retains unresolved outcomes and reports component Monte Carlo uncertainty.

The prospective worst-case component MCSE target remains 0.05.

## Failure behavior

A failed shard may only be rerun for the same wave/shard identity.

It may not be replaced with a new shard definition or alternative scientific replicates.

Partial wave results must not be used to select a method or alter later waves.
