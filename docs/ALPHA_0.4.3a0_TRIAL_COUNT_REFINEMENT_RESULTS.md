## Monte Carlo precision sensitivity

The formal Phase D gate was preregistered as the observed recovery proportion:

`recovery_probability >= 0.80`.

Phase G does not replace that rule after observing the results.

However, because each cell uses only 200 benchmark replicates, the estimated recovery probability itself has Monte Carlo uncertainty.

For the limiting 480 EVSD-weak cell:

- 167 / 200 recovered correctly;
- observed recovery = 0.835;
- approximate Wilson 95% interval = 0.777–0.880.

For the limiting 640 EVSD-weak cell:

- 184 / 200 recovered correctly;
- observed recovery = 0.920;
- approximate Wilson 95% interval = 0.874–0.950.

For the limiting 960 EVSD-weak cell:

- 189 / 200 recovered correctly;
- observed recovery = 0.945;
- approximate Wilson 95% interval = 0.904–0.969.

Thus:

- **480 passes the preregistered point-estimate gate**;
- **640 is the smallest tested design whose limiting cell remains above 0.80 even under this secondary 95% Monte Carlo-precision check**.

This confidence-interval criterion was not preregistered and is therefore reported as a sensitivity analysis, not retroactively substituted for the formal gate.

## Design interpretation

Phase G supports two distinct conclusions.

### Formal conclusion

The trial-count refinement succeeds:

`TARGETED_TRIAL_COUNT_REFINEMENT_PASS`.

All 18 targeted generator × regime × trial-count cells exceed the existing 0.80 point-estimate convention.

There is no current reason to reposition the five operating points.

### Prospective design recommendation

For a future empirical discrimination protocol, **640 target and 640 foil aggregate responses per operating point** is the more defensible starting design among those tested.

It provides:

- worst-cell recovery 0.920;
- zero wrong-family selections in the limiting EVSD-weak cell;
- a substantially reduced inconclusive fraction;
- a useful margin above the 0.80 convention.

The 960 design improves recovery further but incurs 50% more observations than 640 for a smaller incremental gain in the limiting cell (0.920 → 0.945).

The 480 design is more economical but provides substantially less margin around the recovery convention.

This is a design-efficiency judgement within the synthetic benchmark, not a claim that 640 is a universal sample-size optimum.

## Critical translation boundary: aggregate counts are not participants

The benchmark parameter `n_target_per_operating_point` / `n_foil_per_operating_point` represents aggregate Bernoulli response counts supplied to the binomial likelihood.

It must **not** be read as a requirement for one participant to complete 640 target and 640 foil probes at every operating point.

Before human data collection, CEM needs a participant-aware design contract specifying:

- number of participants;
- within- versus between-participant bias manipulation;
- block allocation;
- number of probes per participant;
- repeated-measures dependence;
- participant-level heterogeneity in memory and response bias;
- whether a hierarchical likelihood is required.

Pooling responses as one binomial cell is a simplifying design-recovery approximation and can overstate information if within-participant dependence or heterogeneity is ignored.

Therefore empirical data collection is still blocked.

## Methodological consistency

Wilson & Collins (2019) recommend simulation-based model recovery and generator-by-selected confusion matrices, and emphasize that recovery depends on the parameter regime.

Aushev et al. (2023) similarly treat experimental design as part of cognitive-model selection and show that simulator-based design can target model-discriminating information efficiently.

Phase G follows that logic by changing one design axis, rerunning recovery under both generators, and selecting a design based on discrimination performance rather than assuming that more observations or different operating points are automatically better.
