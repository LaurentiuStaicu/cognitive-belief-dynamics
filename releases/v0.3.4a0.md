# Cognitive Epistemic Model — Alpha 0.3.4a0

[Deschide aplicația / Open app](https://laurentiustaicu.github.io/cognitive-epistemic-model/)

## Calendarul măsurilor selectate

- Calendarul arată numai măsurile din combinația inspectată, la pașii efectivi.
- Un tabel detaliat arată expunerile executate/prevenite, corecția, feedbackul și deciziile.
- Activarea tardivă a reducerii repetiției arată explicit că nu mai previne expuneri.
- Exportul JSON include calendarul, generat din aceeași programare folosită de simulator.

## English

The selected bundle’s schedule shows effective action times and a per-step ledger.
Late repetition reduction explicitly prevents no exposures. The evaluator and UI
share a canonical Python schedule, exported to JSON. Event order and all 96
previous bundle outcomes are checked for exact preservation.

These are abstract simulation steps, not days or a real-world implementation plan.
Equations, coefficients and intervention outcomes remain unchanged and uncalibrated.
Use the hosted app or serve the compiled archive with `python -m http.server 8000`.
Native elementary OS/Flatpak remains planned near v1.
