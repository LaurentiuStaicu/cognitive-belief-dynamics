# Cognitive Epistemic Model — Alpha 0.3.0a0

[Deschide aplicația / Open the app](https://laurentiustaicu.github.io/cognitive-epistemic-model/)

Prima pre-lansare publicată în GitHub Releases. Reunește funcțiile dezvoltate după
etapa inițială 0.2.0a0, care nu a avut un release GitHub separat.

## Ce include

- Înțelegere: șapte variabile explicate, patru mecanisme, formule și limite.
- Hartă: dependențe de calcul, intrări contextuale și registru de dovezi distinct.
- Scenarii: patru rulări, explicații pentru fiecare pas și contribuții la scoruri.
- Comparații: traiectorii sincronizate, diferențe față de repetiția simplă și export.
- Intervenții: 16 combinații, buget de efort, obiective, interacțiuni și sensibilitate.
- Interfață RO/EN, font de sistem, teme deschisă/închisă și navigare din tastatură.
- Pictogramă comună, antet README centrat, etichete și buton de pornire în antet.
- Versiune vizibilă în aplicație, exporturi consecvente și verificare automată.

## Limite și instalare

Nucleul științific rămâne M0: ecuațiile, coeficienții și rezultatele numerice nu se
schimbă prin această lansare. 0.3.0a0 este versiunea distribuției software, nu o
validare empirică nouă. Prioritățile intervențiilor sunt condiționate de ipoteze.

Aplicația web se deschide direct din link, pe Linux, Windows și macOS.
Arhiva web atașată este compilată; pentru rulare locală, dezarhivează și servește
folderul cu `python -m http.server 8000`, apoi deschide `http://localhost:8000`.
Deschiderea directă prin `file://` nu este suportată. Arhivele Source code conțin
sursele pentru dezvoltare. SHA256SUMS.txt verifică arhiva web atașată.

Pachetul nativ elementary OS/Flatpak este planificat pentru apropierea de v1;
această lansare nu conține încă un instalator Flatpak sau Windows.
