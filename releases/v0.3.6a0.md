# Alpha 0.3.6a0 — Scientific readiness and reproducibility

Alpha 0.3.6a0 consolidates the M0 reference model before the first executable M1
extension planned for the 0.4 series.

## Scientific-method changes

- Separate software version, model specification (`M0`) and evidence snapshot.
- Add explicit purpose metadata to published reference runs and explanations.
- Add deterministic local sensitivity-based practical-identifiability diagnostics.
- Keep prediction robustness as a separate diagnostic from parameter identifiability.
- Add a full textual ODD description complementing the registry-driven Visual ODD.
- Expand TRACE with the decision gate for the later M1 extension.
- Add deterministic reproducibility metadata and release provenance boundaries.

## Research-software changes

- Add `CITATION.cff` for machine-readable software citation.
- Use a dynamic release badge in the repository presentation.
- Prepare released web archives for GitHub artifact attestation.
- Keep canonical registries synchronized into the web build.

## Scientific boundaries

The numerical M0 equations and demonstrative coefficients are unchanged.
Alpha 0.3.6a0 does not calibrate M0, prove structural identifiability, estimate
population prevalence, diagnose individuals or introduce numerical MOD.14–16
mechanisms.

The next major scientific step remains M1: explicit separation of actual world,
sampled/observed information, interpretation/world-model construction, editorial
selection/framing and heuristic-policy fit.

## Verification

Release publication remains gated on Python tests, registry validation, exact
regeneration of tracked model outputs, TypeScript/Vite build and Playwright
browser regression.
