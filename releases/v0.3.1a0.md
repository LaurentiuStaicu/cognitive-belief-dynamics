# Cognitive Epistemic Model — Alpha 0.3.1a0 · M0 Visual Stage

[Deschide aplicația / Open app](https://laurentiustaicu.github.io/cognitive-epistemic-model/)

## Noutăți

- Benzi funcționale opționale pentru intrări, memorie/estimări, judecată și decizie.
- Focalizarea vecinătății unui factor și navigare între intrări, ieșiri și formule.
- Marcaje ale relațiilor: sens pozitiv/negativ, interacțiune contextuală sau eșantionare.
- Tururi ghidate manual pentru repetiție, corecție și decizia de distribuire.
- Valori ale rulării direct pe hartă, selector de pas și acces la explicația completă.
- Numărul expunerilor derivă din evenimente; Share este acțiunea efectiv simulată.

Integrarea adaptează propunerea Gemini/Antigravity la arhitectura existentă
TypeScript/Cytoscape. Nu introduce un al doilea set de date sau un framework React.
Benzile sunt organizare computațională; tururile nu sunt experimente de impuls.
Ecuațiile, coeficienții și traiectoriile M0 sunt neschimbate și necalibrate empiric.

## English

Optional functional bands, neighbourhood focus, navigable dependencies, conditional
edge markers and manual guided tours. Graph values replay canonical Python logs;
exposure counts and sampled sharing remain distinct from time and probability.
The supplied visual proposal was adapted to the existing architecture and checked
locally. This is a software update, not new empirical validation.

Use the hosted app or serve the compiled web archive using `python -m http.server 8000`.
The archive and SHA256SUMS are attached after CI verification. Native elementary OS
Flatpak packaging remains planned near v1 and is not included in this release.
