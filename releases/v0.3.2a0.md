# Cognitive Epistemic Model — Alpha 0.3.2a0

[Deschide aplicația / Open app](https://laurentiustaicu.github.io/cognitive-epistemic-model/)

## Înțelegerea mecanismelor

Harta explică acum fiecare dintre cei opt factori din nucleu: rolul în calcul,
valoarea curentă, schimbarea față de pasul anterior, formula și limitele interpretării.
Contribuțiile sunt citite din descompunerea exportată de Python.

Tururile includ acum sursa și evidența, alături de repetiție, corecție și acuratețe.
Navigarea funcționează în ambele sensuri. Selectarea manuală încheie turul, iar
explicația urmărește factorul selectat și cursorul temporal.

## English

Contextual graph explanations cover all eight core factors, with current values,
previous-step differences, equations and interpretation boundaries. A source/evidence
tour and previous-factor navigation extend guided exploration. Manual selection ends
the tour, preventing stale tour state. Values use canonical Python decompositions.

Python equations and scientific trajectories remain unchanged and uncalibrated.
Use the hosted app or serve the web archive with `python -m http.server 8000`.
Native elementary OS/Flatpak packaging remains planned near v1.
