# Cognitive Epistemic Model — Alpha 0.3.3a0

[Deschide aplicația / Open app](https://laurentiustaicu.github.io/cognitive-epistemic-model/)

## Priorități explicabile

- Scorul combinației inspectate este explicat prin cele două obiective și ponderile lor.
- Poziția în clasament și diferența față de cea mai bună alternativă fezabilă sunt vizibile.
- Un tabel compară câștigul și diferența față de prima alegere în fiecare ipoteză.
- Factorii arată separat câștigul măsurii izolate și pierderea la eliminarea din combinație.
- Exportul JSON include această analiză și ipotezele necesare reproducerii sale.

## English

The intervention inspector now explains objective contributions, rank and gap to
its best feasible alternative. Profile comparisons show the selected bundle’s gain
and gap to the top choice under each assumption. Factor tables distinguish standalone
gain from conditional removal loss, preserving negative signs. JSON exports include
the decision audit.

No changes to Python equations, intervention outcomes or optimization rules.
This remains an illustrative weighted-score analysis of uncalibrated M0 simulations,
not validated population decision support or a complete MCDA process.
Use the hosted app or serve the compiled archive with `python -m http.server 8000`.
Native elementary OS/Flatpak remains planned near v1.
